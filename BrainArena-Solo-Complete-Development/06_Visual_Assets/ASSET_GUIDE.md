## Usage
These assets establish an original visual direction. Before store release:
- Refine the logo and icon at required platform sizes.
- Export SVG/PNG variants and test legibility at small sizes.
- Build game-specific sprite atlases with consistent padding/pivots.
- Create 2D character/prop sets and selected Blender 3D scenes.
- Record source, licence, author and version for every external font/audio/asset.
- Do not trace competitor screenshots or reuse copyrighted characters, layouts or levels.

## 3D/Blender brief
Use low-to-mid-poly stylised props, soft bevels, clean silhouettes, baked/efficient lighting, orthographic camera for world cards, transparent PNG renders for selected rewards, and glTF/GLB only for interactive 3D scenes. Keep most gameplay 2D to control memory and build complexity.
