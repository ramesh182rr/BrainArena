# 30-Game Catalogue

All entries are original working concepts. Names may be refined after trademark/store search. Each game must pass a human originality review before public release.

## W1 — Trickster's Lab

*Lateral thinking and unconventional problem-solving*

- **The Missing Clue** — Evidence reconstruction. Players inspect a small scene and place evidence tokens into a causal chain; one clue changes meaning when viewed from a different context.

- **Impossible Answer** — Constraint reframing. A prompt presents a misleading goal; players manipulate a set of rule cards to reveal a valid alternate interpretation, with explicit rule feedback.

- **Hidden Truth** — Perspective switching. A short illustrated scene contains multiple viewpoints; players rotate a viewpoint lens and identify which statement remains consistent across all perspectives.

- **Picture Riddle** — Visual relationship mapping. Players connect visual fragments by semantic relationships, then test the relationship by revealing a transformation result.

- **Rule Breaker** — Rule discovery. Players test objects against a hidden rule by arranging experiments; feedback reveals which property caused a pass/fail result.

## W2 — Logic Kingdom

*Deduction, number logic and structured reasoning*

- **Meow Grid** — Symbol constraint lattice. Place themed tokens into a multi-region board where row, column and region constraints differ per chapter; special 'echo' cells carry one clue across regions.

- **Number Maze** — Arithmetic route planning. Choose a route through gates whose arithmetic transformations update a running value; reach the target without violating bounds.

- **Sequence Master** — Rule composition. Complete sequences where each step applies two alternating transformations; players can inspect a compact rule-history strip.

- **Logic Grid** — Multi-attribute deduction. Resolve a set of characters, objects and time slots using clue tiles; a contradiction detector highlights the smallest conflicting clue set.

- **Number Lock** — Code inference. Crack a lock by proposing short number strings; feedback marks positional and value constraints using a distinct signal system, with no copied familiar code UI.

## W3 — Spatial Dimension

*Spatial reasoning, orientation and movement planning*

- **Arrow Escape** — Energy-current routing. Rotate junctions and redirect moving energy pulses through a network; multiple pulses have different properties and must reach matching receivers.

- **Block Escape** — Layered cargo choreography. Slide modular cargo platforms across a warehouse board; some platforms can carry smaller pieces, changing which moves are legal.

- **Path Finder** — Living path construction. Draw a route through a shifting garden; each step changes nearby terrain, so the route must be planned as a sequence of state changes.

- **Shape Shift** — Projection assembly. Rotate 3D-like silhouettes and arrange 2D facets so their combined shadow matches a target outline.

- **Mirror World** — Dual-board coordination. Control two linked explorers in mirrored rooms; a move in one room causes a different transformation in the other.

## W4 — Pattern Universe

*Pattern recognition, matching and strategic connections*

- **Dot Connect** — Signal constellation. Connect nodes to route a signal through a graph while satisfying colour and degree constraints; crossings can alter signal phase.

- **Colour Cascade** — Colour ecology. Drop colour droplets into a layered garden; adjacent plants transform according to a local rule table, and the objective is to stabilise the whole board.

- **Pattern Link** — Motif weaving. Trace a path through motif tiles; each tile changes the allowed next motif, creating a chain grammar the player must infer.

- **Limited Moves** — Resource choreography. Use a fixed number of actions to activate a board of mechanisms; action order changes later action costs and available moves.

- **Chain Reaction** — Pulse timing. Trigger one node in a network; pulses travel with delays and can amplify, dampen or redirect at junctions. Reach a target state in a move budget.

## W5 — Memory Vault

*Visual memory, observation and recall*

- **Memory Detective** — Scene reconstruction. Study a lively scene briefly, then rebuild its object relationships on a blank scene map; scoring rewards relational recall, not just object count.

- **Object Recall** — Contextual recall. Observe objects placed in meaningful micro-stories, then answer questions about location, relation and order after an interference task.

- **What's Changed?** — Temporal difference tracking. Watch a scene evolve through several subtle changes, then select the sequence of changes in the correct order.

- **Sequence Recall** — Multi-channel sequence. Remember a sequence of symbols, tones and positions, then reproduce it through a different input channel to avoid simple tapping imitation.

- **Snapshot Memory** — Spatial snapshot. A camera-like view sweeps across a room; players later place landmarks and objects on a coarse map with confidence feedback.

## W6 — Creative Chaos

*Creative reasoning, experimentation and interactive problem-solving*

- **Gravity Lab** — Force-field tinkering. Place limited attractor/repulsor devices to guide a drifting object through gates; gravity direction and field strength are puzzle variables.

- **Draw the Solution** — Stroke engineering. Draw one continuous elastic bridge/brace that redirects a moving object; materials have different flex and anchor rules.

- **Object Illusion** — Property transformation. Combine objects by changing one property at a time (weight, transparency, conductivity, warmth) to satisfy a scene objective.

- **Switch Challenge** — State-machine puzzle. Operate switches that change several linked devices; players infer the transition system and reach a target configuration with limited toggles.

- **Impossible Machine** — Causal machine repair. Inspect a whimsical machine with missing/incorrect components; place modules so the output sequence matches a target rhythm and flow.
