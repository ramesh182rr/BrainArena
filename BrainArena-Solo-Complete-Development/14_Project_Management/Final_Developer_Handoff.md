# Developer Handoff Checklist

Before starting Claude Code:
- [ ] Extract ZIP and open root folder in VS Code.
- [ ] Read README, CLAUDE.md, PRD and Architecture.
- [ ] Create Git repository and first commit.
- [ ] Create development Neon project and store credentials outside repo.
- [ ] Create R2 development bucket.
- [ ] Create Render staging service only when API is ready.
- [ ] Decide auth provider and document the choice.
- [ ] Create asset provenance tracker.
- [ ] Select first vertical-slice game and write its detailed interaction prototype.
- [ ] Build and test on a real Android device.

Before public release:
- [ ] Complete all 30 game GDDs and originality reviews.
- [ ] Complete game implementations and level QA.
- [ ] Complete privacy, account deletion, ad and billing flows.
- [ ] Confirm provider quotas, costs and backup plan.
- [ ] Complete Play Console declarations and store listing review.
