# Solo Developer Roadmap

**Planning estimate:** 5–8 months of focused work; not a delivery guarantee. Content quality, animation and generator validation can extend the schedule.

| Milestone | Scope | Exit gate |
|---|---|---|
| M0 | Product and technical foundation | PRD, GDD, repo conventions, asset pipeline |
| M1 | App shell + game runtime | One game vertical slice works offline |
| M2 | First 6 games | Each has tutorial, scoring, tests and originality review |
| M3 | 15 games + six world shells | Catalogue and progression usable |
| M4 | 30 games | All games pass quality gate |
| M5 | Procedural generation | Seeded validators and regression corpus |
| M6 | Daily Arena | Confidence-aware recommendation and user override |
| M7 | Backend/offline sync | Guest link, idempotent sync, recovery |
| M8 | Monetisation + release | Billing/ads compliance, QA, store readiness |

## Weekly solo cadence
- 1 day: plan, review analytics/bugs and design.
- 3 days: implementation.
- 1 day: testing, balancing and polish.
- Keep a playable build at all times.

## Scope control
If a game is not fun after repeated playtests, redesign or replace it before creating hundreds of levels. Avoid building complex 3D scenes before core gameplay is validated.
