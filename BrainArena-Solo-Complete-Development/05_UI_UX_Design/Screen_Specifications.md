# Screen Specifications

1. **Splash:** logo, version-safe startup, local data migration.
2. **Welcome:** product promise, guest start, privacy link.
3. **Preferences:** session duration and puzzle interests; skippable.
4. **Baseline sampler:** 3–4 short varied samples; clearly optional and non-clinical.
5. **Home:** continue, Daily Arena, featured world, recent games.
6. **Explore:** six worlds, search/filter, game availability and progress.
7. **World detail:** world art, game list, collection progress.
8. **Game intro:** objective, controls, difficulty and offline state.
9. **Gameplay:** board, pause, undo (where appropriate), hint, accessibility.
10. **Level summary:** result, score explanation, replay, next, exit.
11. **Daily Arena:** 3–5 games, estimated time, edit/skip.
12. **Progress:** per-game trends, world progress, achievements.
13. **Profile:** guest/account, settings, privacy, subscription, delete account.
14. **Rewarded ad consent:** explain reward and duration; explicit opt-in and decline.
15. **Offline/sync status:** unobtrusive state, retry and conflict resolution if needed.

## Orientation
Portrait is default. Landscape only for games where board geometry materially benefits; preserve safe areas and pause/resume state on rotation.
