# Analytics Event Taxonomy

Collect only what is needed to improve product quality. Use pseudonymous profile IDs and avoid sensitive data.

Events:
- `onboarding_started`
- `guest_profile_created`
- `baseline_sample_completed`
- `world_opened`
- `game_opened`
- `tutorial_completed`
- `level_started`
- `level_completed`
- `level_failed`
- `hint_requested`
- `daily_arena_generated`
- `daily_arena_started`
- `daily_arena_completed`
- `sync_started`
- `sync_completed`
- `sync_failed`
- `rewarded_ad_opt_in`
- `rewarded_ad_completed`
- `premium_screen_opened`
- `purchase_started`
- `purchase_verified`

Common dimensions: app version, platform, game ID, world ID, game version, difficulty, content version, session mode. Do not include free-form story answers, email address, precise location or other unnecessary personal data.
